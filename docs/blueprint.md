# **App Name**: ScrapSnap

## Core Features:

- Scrap Submission: Allow users to upload a photo of their scrap materials along with a brief description.
- Location Services: Capture the user's current location or allow them to specify an address for pickup.
- AI-Powered Estimation: Use AI to categorize the uploaded scrap and provide a preliminary value estimate as a tool to the user.
- Order Summary: Display estimated scrap value, pickup schedule options, and confirmation details.
- Order Confirmation: Confirmation page to show scrap collection request made.
- User Dashboard: User profile page to track submission history, payment information, and account settings.
- Payment Options: Enable users to specify preferred payment methods (e.g., bank transfer, mobile wallet).

## Style Guidelines:

- Primary color: HSL 44, 87%, 54% (RGB: #F0B123). This vibrant yellow-gold hue reflects the value and worth found in reusable materials, moving beyond literal associations with money to a sense of enlightened investment.
- Background color: HSL 44, 23%, 95% (RGB: #FAF5EF). This choice complements the primary, keeping a gentle focus on content.
- Accent color: HSL 14, 75%, 45% (RGB: #D65613). The saturated, dark-valued orange should stand out as needed for calls to action, yet retain some subtlety.
- Headline font: 'Belleza', a humanist sans-serif aligned to art and design. Body font: 'Alegreya' for longer text passages. Note: currently only Google Fonts are supported.
- Use simple, line-based icons to represent different scrap categories and actions. Icons should be easily recognizable and consistent throughout the application.
- Employ a clean and intuitive layout, prioritizing ease of navigation and clarity of information. Use white space effectively to avoid clutter and create a visually appealing interface.
- Incorporate subtle animations for user feedback and transitions. Avoid distracting or unnecessary animations that detract from the user experience.
